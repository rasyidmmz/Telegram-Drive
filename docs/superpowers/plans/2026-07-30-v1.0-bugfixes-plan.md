# TeleStash v1.0 Bug Fixes & Navigation Alignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve v1.0 split-file part leakage, fix unsafe API fieldset unwrap, inject clean media titles into MPV, align playlist ordering/navigation, and display the official `v1.0.0` version badge in the top-left software header.

**Architecture:** 
1. **Multi-Legacy Caption & Manifest Deserialization**: Rust backend recognizes legacy TeleDrive caption prefixes (`[teledrive-part]`, `[telegram-drive-part]`, etc.) and deserializes legacy `teledrive_split` manifest fields so split parts are hidden and synthesized single-file movies load seamlessly.
2. **Safe API Fieldsets**: Replace unsafe `unwrap()` calls in `api_routes.rs` with safe `map_or` Option pattern.
3. **MPV Title Injection**: `cmd_play_in_mpv` passes `--force-media-title=<title>` for single file and playlist streams, replacing raw message ID numbers with actual file names in MPV OSD and titlebars.
4. **Natural Playlist Sorting & Navigation Alignment**: Frontend natural-sorts playlist files (`Ep 01` -> `Ep 02` -> `Ep 10`) and maps starting indices so Next (`>`) advances forward in episode sequence.
5. **Top-Left Version Display**: `Sidebar.tsx` imports `package.json` version and displays an explicit `v1.0.0` badge next to the TeleStash logo in the top-left header.

**Tech Stack:** Rust (Tauri v2, Serde, Tokio), React 19 (TypeScript, Lucide icons), MPV sidecar.

## Global Constraints

- Windows 11 x64 only.
- Strict Ponytail principles: minimal diffs, zero unnecessary abstractions, root-cause guards.
- Quality Gates: `npx tsc --noEmit` on `app/`, `git diff --check`, `cargo test` on `app/src-tauri/`.
